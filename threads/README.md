# Threads

Standing thinking. One file per live thread. Mirrored to
`hub-briefs/threads/` by the 8:30 sync, so it's readable from any browser
including the work laptop.

## Format

Four sections, nothing else:

- **Thesis** — the claim, in one or two sentences. Rewrite it when it moves.
- **Holds up** — evidence for, each with a date and a source.
- **Undermines** — evidence against. If this section is empty the thread is
  decoration, not thinking.
- **Open** — questions you can't answer yet.

## Discipline

- Three to five live threads. Not more.
- Tended weekly, about twenty minutes. That session is the whole system;
  everything else is plumbing.
- A thread that hasn't moved in two months gets archived. Same rule as
  spec section 10: kill or fix, no zombies.
- Threads are the raw material for short pieces. When a thread has enough
  in "Holds up" and "Undermines" to be interesting to someone else, that's
  a draft.
